# Valeur ou représentation ?

**Niveau :** base  
**Format :** lecture de code

Sans exécuter :

```python
raw = "24"
count = int(raw)
doubled = count * 2
label = raw + "h"

print(count, doubled, label)
```

Pour chaque variable, donnez :

- sa valeur ;
- son type ;
- l'opération qui a permis de l'obtenir.
