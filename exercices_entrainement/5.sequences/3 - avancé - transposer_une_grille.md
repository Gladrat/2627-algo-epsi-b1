# Transposer une grille

**Niveau :** avancé  
**Format :** pratique

On donne :

```python
grid = [
    [1, 2, 3],
    [4, 5, 6],
]
```

Construisez avec des boucles une nouvelle grille :

```python
[
    [1, 4],
    [2, 5],
    [3, 6],
]
```

Contraintes :

- ne pas modifier `grid` ;
- utiliser des boucles et `.append()` ;
- ne pas utiliser de raccourci Python spécialisé.

Avant de coder, expliquez ce que devient une position `grid[row][column]` dans la nouvelle grille.
