# Retrouver un instant dans un flux vidéo

**Niveau :** avancé  
**Format :** pratique

Une vidéo est lue à **60 images par seconde**. On se trouve à l'image numéro **10 987**, en comptant à partir de 0.

Sans utiliser de condition ni de boucle, déterminez :

- le nombre de secondes complètes écoulées ;
- le numéro de l'image à l'intérieur de la seconde courante ;
- le nombre de minutes complètes ;
- le nombre de secondes restantes dans la minute.

Expliquez d'abord comment `//` et `%` permettent de décomposer la valeur, puis traduisez en Python.
