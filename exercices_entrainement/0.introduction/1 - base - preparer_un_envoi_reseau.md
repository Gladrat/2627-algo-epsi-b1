# Préparer un envoi réseau

**Niveau :** base  
**Format :** pratique guidée

Un programme doit envoyer **6 messages** de **180 octets** chacun. Un en-tête de **24 octets** est ajouté une seule fois à l'envoi.

Commencez par décrire votre démarche :

1. identifiez les entrées et la sortie attendue ;
2. décrivez les étapes du calcul ;
3. calculez la taille totale envoyée ;
4. traduisez ensuite votre démarche en Python.
