# Espace restant

**Niveau :** base  
**Format :** pratique

Écrivez :

```python
remaining_storage(capacity, used)
```

qui renvoie l'espace restant.

Hypothèse :

```python
0 <= used <= capacity
```

Ajoutez au moins trois `assert`, dont :

- aucun espace utilisé ;
- stockage entièrement utilisé ;
- un cas intermédiaire.
