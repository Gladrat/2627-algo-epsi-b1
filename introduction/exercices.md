# Exercice facile — Le billet de concert

Une billetterie vend des places à 32 €.

Pour une commande de 3 places :

- frais fixes : 2,50 € ;
- frais de service : 5 % du prix des places, hors frais fixes.

Sans commencer par Python :

1. identifiez les entrées ;
2. écrivez les étapes de l'algorithme ;
3. calculez le montant final ;
4. traduisez ensuite votre solution en Python.

# Exercice difficile — Livraison de batteries

Un drone doit transporter des batteries.

Données :

- une batterie pèse **430 g** ;
- le drone peut transporter au maximum **2 500 g** par trajet ;
- une commande contient **17 batteries**.

Sans commencer par Python :

1. déterminez combien de batteries le drone peut transporter au maximum par trajet ;
2. déterminez combien de trajets complets de capacité maximale il peut effectuer ;
3. déterminez combien de batteries resteront pour le dernier trajet ;
4. déterminez le nombre total de trajets nécessaires ;
5. faites une trace des calculs ;
6. traduisez ensuite votre solution en Python.

Contrainte : résoudre le problème uniquement avec les opérations arithmétiques vues jusqu'ici.
