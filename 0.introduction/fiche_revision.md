# Concepts clés

- **Problème** : ce qu'on cherche à résoudre.
- **Algorithme** : la méthode générale, indépendante du langage.
- **Programme** : la traduction exécutable de l'algorithme dans un langage.
- Une solution doit être décrite assez précisément pour savoir quoi faire à chaque étape.
- Schéma de base : **entrées → traitements → sorties**.
- Une **trace** consiste à exécuter mentalement le programme instruction par instruction et à suivre l'évolution des valeurs.

# Outils vus

```text
17 // 5 = 3   → quotient entier
17 % 5  = 2   → reste
```

`//` permet de former des groupes entiers ; `%` permet de récupérer ce qui reste.

# Réflexe à appliquer

Avant le code :

1. Quelles sont les entrées ?
2. Quelle sortie doit être obtenue ?
3. Quelles étapes intermédiaires permettent d'y arriver ?
4. Avec quel exemple simple peut-on vérifier le raisonnement ?

# Pièges à éviter

- commencer par écrire du Python sans avoir compris le problème ;
- donner des instructions trop vagues ;
- regarder uniquement le résultat final sans suivre les étapes intermédiaires.
